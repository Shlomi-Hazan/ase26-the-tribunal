# Stakeholders

## Primary User

The end user submits a case, configures participants, runs the Tribunal, and inspects the resulting arguments, verdicts, reasoning, protocol, and economics.

## Project Owner / Engineer

The student developer is responsible for specification, architecture, security, model configuration, verification, cost control, maintainability, and repository auditability.

## Course Evaluator

The instructor must be able to inspect repository evidence and verify that the engineering process is explicit, disciplined, and traceable.

## AI Provider

OpenRouter provides access to models whose availability, pricing, usage reporting, and latency affect runtime behaviour.

## Hosting/Data Providers

Infrastructure providers will eventually host the application and persistent data, affecting deployment, reliability, storage, and operational constraints.
