# Out of Scope

The initial project deliberately excludes:

- real legal advice
- legal authority
- model training
- fine-tuning
- RAG
- vector databases
- social-network features
- user-to-user messaging
- payments
- voice interaction
- image generation
- live human juries
- arbitrary numbers of advocates
- arbitrary numbers of judges
- an LLM call for deterministic majority calculation
- automatic expensive-model fallback that can break the run budget
- optimization for maximum legal-reasoning performance

Authentication is not required for the initial Tribunal unless a later course, security, or deployment requirement makes it necessary.
