# Assumptions

These assumptions are not settled requirements unless a later specification milestone confirms them.

1. The Charge Sheet can describe a disputed act or question and does not have to represent a real criminal offence.
2. The final verdict vocabulary is not yet fixed; for example, `GUILTY / NOT_GUILTY` versus another binary vocabulary remains a specification decision.
3. Exact supported upload formats are not yet fixed.
4. Shared-model and separate-model configurations are required based on the current course notes.
5. A true agent-execution configuration remains to be clarified from the course's oral guidance.
6. OpenRouter usage and pricing metadata will be verified technically before implementation relies on it.
7. Free/very-low-cost model availability can change over time.
8. The $5 ceiling applies to one complete Tribunal run.
9. Majority calculation requires no additional AI reasoning.
10. Personalities are user-provided behavioural/system context; automatic AI generation of personalities is not required.
11. The protocol should be assembled from the stored participant outputs rather than generated through an eighth LLM call.
12. Authentication remains unnecessary unless later requirements establish a reason for it.
